# Информационная система "Учёт отпусков сотрудников"

## Описание проекта
Данный проект предназначен для автоматизации процессов оформления и контроля отпусков сотрудников,заменяя бумажные приказы и заявления на отпуск цифровой базой данных.

## Роли в системе и права доступа
*  **Администратор(кадровик):** Обладает полными правами управления данными. Отвечает за составление графиков отпусков, просматривает истории отпусков сотрудников,выплачивает отпускные работникам.
*  **Пользователь(сотрудник):** Обладает правами доступа только в режиме чтения.Может просматривать статус заявления на отпуск,отслеживать начало и конец отпуска,заполнять заявление на отпуск.

## Функционал и возможности

### Администратор
*  Добавление сотрудников
*  Составление графиков отпусков
*  Выплата отпускных сотрудникам
*  Просмотр истории отпусков каждого сотрудника

### Пользователь
*  Заполнение заявления на отпуск
*  Просмотр статуса заявления
*  Отслеживание начала и конца отпуска

## Стек технологий
*  **Язык програмирования:** Python 3.14
*  **Среда разработки:** VS Code
*  **Система контроля версий:** Git / GitHub
